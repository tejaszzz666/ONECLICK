Launch.

Paste a public GitHub repository. Launch reads it, tells you what it needs, and shows the free way to run it. No setup.

Launch reads a public GitHub repository and reports how it would be run. ONECLICK servers never install, build or run it. For Node.js projects, StackBlitz can run it in your browser in a new tab (a third-party service); other options open free cloud runners.

Three steps. Zero setup.

1 · PASTE

Any public GitHub repo. A full link or just owner/repo.

2 · ANALYZE

Launch reads it through GitHub and finds the stack, install, build and start commands, and environment variables.

3 · RUN

Pick a free runner. StackBlitz for Node.js, Codespaces for anything else. They open in a new tab on your own free quota.

Libraries and packages are reported as "nothing to launch". Private repositories are not supported.
